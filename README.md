# To-Do List Life Dashboard

A personal productivity dashboard built with vanilla JavaScript that combines time tracking, task management, and quick access to your favorite links. Stay focused and organized with a clean, customizable interface that adapts to your workflow.

[View Live Demo](https://USERNAME.github.io/REPO-NAME/)

## ✨ Features

### 📅 Personalized Greeting
- **Live Time Display**: Real-time clock with HH:MM:SS format, updated every second
- **Current Date**: Full date display with weekday, month, and day
- **Custom Name**: Add your name to personalize the greeting (saved to Local Storage)

### ⏰ Focus Timer
- **Pomodoro Timer**: Countdown timer for focused work sessions
- **Start/Stop/Reset Controls**: Full control over your timer
- **Custom Duration**: Set custom timer duration from 1 to 120 minutes
- **Browser Notifications**: Get notified when your timer completes
- **Persistent Duration**: Your custom timer duration is saved and persists across sessions

### ✅ To-Do List
- **Add Tasks**: Quickly add new tasks with a simple input form
- **Mark as Done**: Check off completed tasks with visual strike-through
- **Delete Tasks**: Remove tasks you no longer need
- **Persistent Storage**: All tasks are automatically saved to Local Storage
- **Instant Updates**: UI updates in real-time as you manage your tasks

### 🔗 Quick Links
- **Add Links**: Save frequently visited websites with custom names
- **Open in New Tab**: Links open securely in a new browser tab
- **Delete Links**: Remove links you no longer need
- **Persistent Storage**: All links are saved to Local Storage

### 🎨 Light/Dark Mode
- **Theme Toggle**: Switch between light and dark themes with one click
- **Persistent Preference**: Your theme choice is saved and applied on every visit

## 🛠️ Tech Stack

- **HTML5**: Semantic markup for better accessibility
- **CSS3**: Modern styling with CSS variables and responsive design
- **Vanilla JavaScript**: No frameworks or libraries - pure JavaScript
- **Local Storage API**: Client-side data persistence
- **Browser Notification API**: Timer completion alerts

**No backend required. No build tools needed. No dependencies to install.**

## 🚀 How to Run Locally

No installation or setup required! Simply:

1. Download or clone this repository
2. Open `index.html` in any modern web browser
3. Start using the dashboard immediately

**Browser Requirements:**
- Chrome, Firefox, Safari, or Edge (latest versions recommended)
- JavaScript enabled
- Local Storage enabled
